# Policy templates

These are **editable starting points**, not legal advice. Fill in every `[bracketed]` item, remove anything that doesn't apply, and have a qualified Canadian advisor review them (consumer protection rules differ by province, and Québec has additional requirements). Paste the final text into **Shopify admin → Settings → Policies**; the theme links to them automatically in the footer.

Shopify can also generate starter policies on that page — you can compare against these.
