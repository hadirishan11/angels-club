## C. Assets you must provide (before launch)

| Asset | Where it goes | Spec |
|---|---|---|
| **Product photography** for every fragrance (front, angle, in-hand or scale shot), owned or licensed by you | Product media | Square or 4:5, ≥ 1600 px, neutral or brand backgrounds. Don't copy designer campaign or retailer images |
| **Accurate product data**: brand, name, size, concentration, notes, family, price (CAD), SKU, weight, inventory | Products + metafields (`docs/METAFIELDS.md`) | Never estimate stock or ratings |
| Real **packaging photography** (Noir black box, Rosé pink box), once produced | Gifting experience → image pickers | 1100 px+ wide |
| Discovery / gift set photography | Discovery sets → image; set products | 1200 px+ |
| Social share image | Theme settings → Social media | 1200 × 628 |
| Brand logos for *Shop by brand* — **only if licensed** | Shop by brand → Brand logo blocks | Transparent SVG/PNG |
| Optional GLB 3D models of real products (if you have rights) | Product media (Shopify native 3D) | < 15 MB, glTF binary |
| About-page story, contact details, policy text | Pages / Policies | See `docs/LAUNCH_CHECKLIST.md` |
