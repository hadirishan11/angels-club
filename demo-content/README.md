# Demo content (testing only)

- `products-sample.csv` — six **draft** demo products (two worlds) priced at $1.00, untracked inventory, with metafield columns. Import via Products → Import. Create the metafield definitions in `docs/METAFIELDS.md` first, otherwise the metafield columns are ignored.
- `product-images/` — generic, label-free bottle renders (`demo-noir-0X.webp`, `demo-rose-0X.webp`). Upload them to the matching demo products manually (CSV image import requires public URLs).

These products are clearly marked DEMO and must be deleted (or kept as draft) before launch. They are not real products and the prices are placeholders.
